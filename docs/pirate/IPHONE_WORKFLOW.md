# iPhone workflow

1. Open the GitHub mobile app or Safari, repository `chintudagar541-stack/wanderly`, branch `claude/dagar-blender`.
2. To render: ask Claude (claude.ai app) to bump `blender/pirate/job.json` (`mode`: `stills` or `video`, `rev` +1) and push. The Actions tab shows progress.
3. Stills appear in `previews/pirate/*.jpg`; the full video as `previews/pirate/final.mp4` (open the file in GitHub and use Download).
4. Save to Photos from the Files app, then upload to YouTube Studio.
5. Voiceover: replace `blender/pirate/voice.mp3` (same length, or update `total` and subtitle times in `film.json`).
